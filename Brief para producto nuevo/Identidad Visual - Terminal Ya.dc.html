Sobre fondo oscuro

Aire mínimo alrededor: la altura del cuadro interior. Nunca menor a 24px de lado en pantalla.

Bajo 32px se usa solo el isotipo; el texto deja de leerse en la barra superior.

Dónde se tocan los roles

Cuatro traspasos. Cada uno es un punto donde hoy se pierde información, y donde la app tiene que dejar una prueba que sirva para las dos partes.

V·04 → C·03
Vendedor entrega al conductor
Prueba: foto del paquete y hora del recojo.
C·04 → S·02
Conductor entrega en sucursal
Prueba: código de 4 dígitos, funciona sin señal.
S·03 → D·02
Sucursal despacha el bus
Aquí muere el mapa en vivo y empiezan los hitos.
S·04 → D·04
Sucursal entrega al destinatario
Prueba: cédula, código y firma. Cierra el cobro.
Qué construir primero

Para la demo de este mes: el carril completo del vendedor (V·01 → V·04) navegable, y una pantalla estática por cada otro rol. Lo que no se puede simular es el traspaso C·04 → S·02: ese conviene mostrarlo funcionando, porque es el que reemplaza al cuaderno.
Regla de la marca

Terminal Ya no vende velocidad, vende saber dónde está el paquete. Cuando no lo sabemos, la pantalla lo dice con las mismas letras con que da una buena noticia.
